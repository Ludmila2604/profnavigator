# Техническое задание: «ПрофНавигатор»

## Цель и формат

«ПрофНавигатор» — одностраничный русскоязычный сайт с интерактивным профориентационным тестом. Он помогает школьникам, студентам и взрослым определить подходящие направления карьеры по интересам, сильным сторонам и предпочтительному формату работы. Первая версия полностью статическая: без регистрации, сервера и базы данных; развёртывается на GitHub Pages.

## Пользовательский сценарий

1. Пользователь видит главный экран с описанием и кнопкой «Пройти тест».
2. Отвечает на 20 вопросов, выбирая один из 4 вариантов.
3. Видит номер вопроса, прогресс и может вернуться назад.
4. После последнего ответа получает три подходящих направления с процентом соответствия и пояснением.
5. Может повторить тест или поделиться ссылкой.

## Состав интерфейса

- Шапка: название, ссылки «О тесте» и «Направления».
- Главный экран: слоган, описание, CTA-кнопка, тематическая иллюстрация.
- Раздел «Как это работает»: три шага.
- Сетка из 8 профессиональных сфер: IT, дизайн, бизнес, наука, образование, финансы, право, инженерия.
- Полноэкранный тест: один вопрос, варианты ответов, прогресс, «Назад» и «Далее».
- Экран результата: топ-3 карточки, проценты, объяснения, кнопки повторного прохождения и публикации ссылки.
- Подвал с дисклеймером, что тест носит ознакомительный характер.

## Логика

Каждый вариант ответа начисляет баллы одной или нескольким профессиональным сферам. По окончании теста баллы суммируются, сферы сортируются по убыванию, затем показываются первые три. Кнопка «Далее» недоступна без ответа. Новое прохождение очищает предыдущие ответы и результат.

## Требования к качеству

- HTML5, CSS3 и JavaScript без серверной части и обязательных зависимостей.
- Корректная работа в актуальных Chrome, Edge, Firefox и Safari.
- Адаптивность для экранов от 320 px.
- Семантическая разметка, доступность с клавиатуры, понятные `aria-label` и контрастный текст.
- Русский интерфейс, метаданные `title`, `description` и Open Graph.
- HTTPS после публикации через GitHub Pages.

## Структура и развёртывание

```text
profnavigator/

├── README.md
├── TECHNICAL_SPEC.md
├── css/style.css
└── js/
    ├── app.js
```

Для публикации: создать публичный репозиторий `profnavigator`, отправить ветку `main`, затем в **Settings → Pages** выбрать **Deploy from a branch**, ветку `main` и каталог `/(root)`. Адрес: `https://<логин>.github.io/profnavigator/`.
