# ПрофНавигатор

Интерактивный сайт с тестом, который помогает определить подходящие профессиональные направления.

## Запуск

Откройте файл `index.html` в браузере. Сервер и установка зависимостей не нужны.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `profnavigator`.
2. Загрузите в него содержимое этого проекта.
3. В GitHub откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
5. Сайт будет доступен по адресу `https://ваш-логин.github.io/profnavigator/`.

## Структура

- `index.html` — разметка сайта;
- `css/style.css` — стили и адаптивный дизайн;
- `js/data.js` — вопросы и профессиональные направления;
- `js/app.js` — логика теста и подсчёта результатов.
